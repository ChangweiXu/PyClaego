# Cron 表达式速查

标准 5 段格式：`分钟 小时 日期 月份 星期`

```
┌───────── 分钟  (0–59)
│ ┌─────── 小时  (0–23)
│ │ ┌───── 日期  (1–31)
│ │ │ ┌─── 月份  (1–12)
│ │ │ │ ┌─ 星期  (0–7, 0 和 7 均为周日)
│ │ │ │ │
* * * * *
```

## 特殊字符

| 字符 | 含义 | 示例 |
|------|------|------|
| `*` | 任意值 | `* * * * *` = 每分钟 |
| `,` | 枚举 | `0,30 * * * *` = 每小时 0 分和 30 分 |
| `-` | 范围 | `0 9-18 * * *` = 09:00–18:00 每整点 |
| `/` | 步进 | `*/15 * * * *` = 每 15 分钟；`0 8-22/2 * * *` = 08:00 起每 2 小时 |
| `1-5` (星期) | 周一至周五 | `0 9 * * 1-5` = 工作日 09:00 |

## 常用模板

| 描述 | 表达式 |
|------|--------|
| 每天 08:00 | `0 8 * * *` |
| 工作日 09:00 | `0 9 * * 1-5` |
| 每 30 分钟 | `*/30 * * * *` |
| 工作日 09:00–18:00 每整点 | `0 9-18 * * 1-5` |
| 每天 08:00–22:00 每 2 小时 | `0 8-22/2 * * *` |
| 每 4 小时 | `0 */4 * * *` |
| 每周一 09:00 | `0 9 * * 1` |
| 每月 1 日 00:00 | `0 0 1 * *` |
| 每天 20:00 | `0 20 * * *` |
| 每天 06:00 和 18:00 | `0 6,18 * * *` |
