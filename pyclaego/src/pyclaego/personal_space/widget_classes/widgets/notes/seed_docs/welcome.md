# Welcome to Notes

This is your personal Markdown knowledge base. Here's what you can do:

## Quick Start

- **Write** any `.md` file in the editor on the right
- **Organise** files into folders using the file tree on the left
- **Search** full-text with the Search drawer (top of sidebar)
- **Connect** notes with `[[relative/path/to/other.md]]` links
- **Tag** content with `[[#tagname]]` references
- **Ask** the Librarian (bottom of sidebar) for conversational help

## Syntax Reference

### Doc Links

Reference another note with a wiki-style link:

```
[[getting-started.md]]
[[examples/note-a.md]]
[[examples/note-a.md:introduction]]   ← link to a section
```

These become graph edges visible in the **Graph** drawer.

### Tags

Tag a note inline:

```
[[#research]]
[[#todo]]
[[#project-x]]
```

Valid tag characters: `a-z`, `0-9`, `-`, `_`. Tags are visible in the **Tags** drawer.

### Standard Markdown

Headers, bold, italic, code blocks, lists, tables — all standard CommonMark syntax is supported.
