# Getting Started

[[#guide]] [[#onboarding]]

This note walks you through the core workflow.

## 1. Create a Note

Click `+` next to any folder in the file tree, or right-click a folder and select **New file here**.

## 2. Link Notes

Type `[[` and start typing a file path. Example:

```
See the overview in [[welcome.md]] for the full syntax reference.
```

Once you save, the link becomes a graph edge — visible in the **Graph** drawer.

## 3. Add Tags

Tags help you categorise notes without folder hierarchy:

```
This is a research note. [[#research]]
Action item: review results. [[#todo]]
```

Open the **Tags** drawer to browse by tag and see all associated notes.

## 4. Search

Click **Search** in the sidebar. Type any keyword — full-text search runs against all notes in this vault. Click a result to open it in the editor.

## 5. Ask the Librarian

Click **Librarian** at the bottom of the sidebar. The Librarian is an AI assistant with knowledge of your vault. Ask it to summarise notes, find related ideas, or help you draft new content.
